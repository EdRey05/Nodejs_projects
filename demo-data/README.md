# Fictional demonstration data

001/Synthetic_FinancialData.xlsx is the original input: three accounts, 30 transactions, savings balance 4290. All banks, brokers and assets are fictional. expected.json describes that input. 001/FinancialData.xlsx is the actual app export after adding one 100 contribution: 31 transactions, savings balance 4390. Import/export round-trip was checked through the real packaged UI.

002/Notebook.md is the original fictional note. 002/Notebook-edited.md is the actual saved/reopened editor output. Nothing here comes from a company, patient or personal account. Use copies when experimenting; the editor saves directly to the selected file.

Portable folders put supplied samples under examples/. Repository links use demo-data/. Runtime and recording evidence is retained in Desktop/Nodejs_standarization and media receipts in Images_GIFs_Videos/recordings.json. No 003 demonstration data is published.
